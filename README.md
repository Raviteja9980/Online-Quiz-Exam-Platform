# 📝 QuizMaster — Online Quiz & Exam Platform

A modern, full-featured quiz and exam platform built with React. Take timed quizzes, compete on leaderboards, earn certificates, and track performance through an analytics dashboard.

## ✨ Features

### Core
- 🏠 **Quiz Library** — Browse quizzes by category with difficulty and duration info
- ⏱ **Timed Exams** — Countdown timer with auto-submit on expiry
- ✅ **Multiple Choice** — 4-option questions with instant answer feedback
- 📊 **Results & Review** — Score breakdown, correct/wrong count, per-question review

### Advanced
- 🏆 **Leaderboard** — Global rankings with streaks and medals
- 📜 **Certificate Generation** — Downloadable achievement certificates for passing scores
- 📈 **Analytics Dashboard** — Weekly activity, score distribution, and category breakdown
- ✏️ **Quiz Creator** — Build and publish your own quizzes with custom questions

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/quiz-platform.git
cd quiz-platform
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🛠 Tech Stack

- **React** — UI and state management
- **Vite** — Build tool and dev server
- **Pure CSS-in-JS** — No external UI library, fully custom styling
